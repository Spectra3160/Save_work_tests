# Как запускать приложение на Windows (3 простых способа)

## Способ 1. Установка на рабочий стол без сборки (самый простой)
Откройте приложение в браузере **Microsoft Edge** или **Google Chrome**, нажмите на значок установки в адресной строке (или кнопку **«Установить на ПК»** в разделе **«Скачать / EXE»**).
- Появится ярлык **«Охрана труда»** на рабочем столе и в меню «Пуск».
- Открывается в отдельном окне без панели браузера.
- Работает без интернета и сохраняет все ответы.

## Способ 2. Один автономный файл (без установки)
В разделе **«Скачать / EXE»** нажмите **«Скачать файл (.html)»**. Полученный файл содержит все 7 документов, 44 вопроса, 286 тестовых заданий и ваш прогресс, и открывается двойным кликом на любом ПК Windows без интернета.

## Способ 3. Сборка настоящего `.exe` файла двойным кликом
Если вам нужен именно исполняемый `.exe`:
1. Установите **Node.js (LTS)** с сайта `https://nodejs.org/` (если ещё не установлен).
2. Распакуйте папку проекта и **дважды кликните по файлу `Build_EXE_Windows.bat`**.
3. Дождитесь завершения — скрипт автоматически откроет папку `release/` с двумя готовыми файлами:
   - Установщик Windows (`Setup .exe`) с ярлыком на рабочем столе.
   - Портативный файл (`Portable .exe`), не требующий установки.
   Ответы автоматически сохраняются на диск в `%APPDATA%\Охрана труда — Тренажёр\progress.json`.
